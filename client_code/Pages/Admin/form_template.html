Painting studio

“Paint this book” sends each page's picture to Image Enhancer, Arkvital's own image service, which repaints it on the studio PC with an open image model. Little Hero Books needs two App Secrets from Image Enhancer's Apps & keys page: image_enhancer_key and image_enhancer_webhook_secret (Anvil editor: App Secrets).

Example people and content, so the app never looks empty for the first visitors. Demo rows are flagged, so removing them never touches real data. Once removed, it stays removed until you load it again.
